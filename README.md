# 💻 Web Applications & Monetization Dashboards

A curated collection of client-side web applications, interactive productivity launchers, and revenue dashboards built and maintained by **Sanjeev Kumar ([@Nova-Jaat](https://github.com/Nova-Jaat))**.

---

## 🚀 Included Web Applications

### 1. 📊 [Ad Monetization Dashboard](ad-monetization-dashboard/)
* **Tech Stack**: Vanilla JavaScript (ES6+), HTML5, CSS3 Custom Properties.
* **Purpose**: Interactive dashboard tracking ad impressions, revenue estimations, eCPM calculations, and conversion metrics.
* **Core Files**:
  * [`index.html`](ad-monetization-dashboard/index.html) — Application structure and UI components.
  * [`style.css`](ad-monetization-dashboard/style.css) — Modern dark-mode styling and responsive grid layout.
  * [`app.js`](ad-monetization-dashboard/app.js) — Real-time event handling, calculation engine, and state management.

### 2. 🎯 [ATS Direct Job Search Launcher](ats-job-search-launcher/)
* **Tech Stack**: HTML5, Modern CSS, Dynamic JavaScript URL Builder.
* **Purpose**: High-velocity job search launcher that executes Boolean search operators across Google Careers, LinkedIn Direct, Wellfound, and Indeed to bypass automated keyword filters and discover direct hiring manager postings.
* **Core File**:
  * [`index.html`](ats-job-search-launcher/index.html) — Standalone single-file application with zero external dependencies.

## 🏃 Quick Start / How to Run Locally

Both applications run directly in any modern browser without requiring a server or build step:

```bash
# Clone the repository
git clone https://github.com/Nova-Jaat/Web-Monetization-Apps.git
cd Web-Monetization-Apps

# Option A: Open directly in your browser
start ad-monetization-dashboard/index.html
start ats-job-search-launcher/index.html

# Option B: Run with lightweight local server (Python)
python -m http.server 8080
# Visit http://localhost:8080/ad-monetization-dashboard/ or /ats-job-search-launcher/
```
